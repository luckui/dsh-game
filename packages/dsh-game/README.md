# dsh-game：让大肥鱼在 DeepSeek Harness 里玩游戏

DeepSeek Harness（DSH）插件。装上以后，你的 DSH agent 会以 Q 版鲸鱼娘「大肥鱼」的身份玩游戏，你在旁边看：
游戏画面直接显示在 DSH 里，旁边是她的思考过程（终端），她对剧情的反应会用语音念出来，配上表情动画。

现在有三款游戏：
- **《心跳文学部》**（Doki Doki Literature Club!）：从 Steam 免费安装，她从头玩到结局。
- **狼人杀**（插件自带）：最多九位 AI 娘同桌的 6~9 人局，DeepSeek、Grok、Claude、GPT、Gemini、Qwen、Mistral、GLM、Kimi，大肥鱼是其中一位，你在上帝视角看全部身份和每个人的心声，也可以自己拿一张身份牌坐上去（10 人局）。
- **Minecraft**（Java 版，生存）：她自己进一个服务器玩，砍树、合成、挖矿、熔炼、打怪、躲怪过夜；你用一个「摄像机客户端」看她的视角，画面上有她的血量、饱食度和快捷栏。

> 预览版。

## 她能做什么

- **自己操作游戏**：在主菜单开新游戏或读档、给主角起名字、做选项、写诗挑词，第三幕删角色文件也是她自己决定。
- **边玩边说**：想法通过豆包语音念出来，大肥鱼会配合表情动画；没配语音就只显示字幕。
- **导演模式**：日常段落自动快进，交给她一段摘要；关键剧情放慢，一场一场地看。
- **你可以随时插话**：在游戏画面下面的输入框跟她说话，游戏会先停下等她回答；点停止，游戏马上停住。
- **存档**：每个时刻自动存一次（插件自己的存档位），下次从游戏库「继续玩」就接着玩。

## 狼人杀

- **规则**：屠边，每局随机排座位、发身份。9 人是「预女猎」标准局（3 狼、预言家、女巫、猎人、3 平民）；8 人少一个平民；7 人 2 狼、预女猎、2 平民；6 人 2 狼、预言家、女巫、2 平民。
- **牌桌**：古堡圆厅里的魔法阵祭坛（3D 透视），九张角色卡立在阵上。
  - 开场镜头从高处俯冲下来，魔法阵展开，角色卡依次升起；魔法阵的颜色跟着阶段变（夜晚冷蓝、狼人猩红、预言家紫、女巫翠绿、白天金色）。
  - 轮到谁说话，祭坛就把谁转到正前方、打上光，台词在底部的对白框里逐字出现，每个角色有自己的声音。
  - 夜里轮到谁睁眼，谁的卡亮起；投票时地面上画出投票连线和票数；出局的人倒下变灰；结局全员翻牌。
- **两种视角**（右上角切换）：「上帝视角」（默认）看全部身份，夜里每个动作都有特效和字幕（爪痕、查验光束、药水、枪线、投票箭头），每个人做决定前的心声用各自的声音念出来；「大肥鱼视角」只看她知道的事，代入她玩。右上角的「记录」能翻看牌桌上发生过的事。
- **大肥鱼**：她自己决定发言、投票、刀人、查验、用药和开枪。她回复里写的话是只有你和观众能听到的心声（会念出来），牌桌上的其他 AI 听不到。
- **你自己上桌**：在开局设置里点「主人」卡。这局是主人视角，只看得到你自己知道的事（右上角写着你是几号、什么身份），不能切上帝视角。轮到你时牌桌底部会出现行动条（全屏时也能操作）：发言、遗言、狼队私聊打字说（只显示文字，不念）；刀人、查验、投票、开枪直接点桌上亮着的人，再点「确认」；女巫有救、用毒药、不用药。右上角「你知道的」列出你的身份和夜里得到的信息。这局不能私聊大肥鱼，她的心声你也听不到（右边的思考终端封起来），结束后在牌桌右上「复盘」里看。
- **开局设置**：在游戏库里选中狼人杀，横幅下面就是。改了马上保存。
  - 做成「入座」界面：每个座位一张角色卡，点头像让她上桌或离席；卡下面的 ◀ ▶ 换驱动：默认模型、DSH 里配好的任意模型、Codex（用你电脑上的 Codex，走你自己的 ChatGPT 订阅，每步十几到二十几秒）、不上桌。
  - 一局结束后，游戏标题栏有「改座位」，点了回到这里。
  - 不上桌的人多了少了，人数和身份组合跟着变（6~10 人）。
  - 最后一张「主人」卡是你自己：点头像上桌。九位 AI 加你是 10 人局（3 狼、预言家、女巫、猎人、4 平民）。
  - 每个座位旁边写着能不能用：模型 DSH 里有没有、Codex 装没装、登没登录。有问题时「让大肥鱼玩」按钮不能点，并写出原因。
  - 模型的 API Key 在 DSH 设置的「模型」里配，开局设置只选用哪个。
- **对局中出错**：某个 AI 一步没做成（模型报错、Codex 没回应），它的卡上会挂一个 ⚠ 角标，左上角显示一共几步没做成，点开「记录」能看到原因。用 Codex 的座位想得久时卡下面显示「思考中」。

## Minecraft

- **她自己玩**：她以玩家的身份进一个 Java 版服务器（默认名字 `DaFeiYu`），自己定目标、自己决定做什么。能做的事：采集、合成（缺的中间材料和工作台会自己先做）、熔炼、走到坐标、找方块和生物、打怪、放方块、装备、丢东西和捡东西、躲到地下、逃跑、睡觉、在游戏聊天里打字。长动作在后台做，她可以一次排好几件。
- **盖房子：房子是她自己设计的**。她用字符图画图纸（一张图例，加上从下往上一层层的字符图），交上去先拿到正面、侧面、俯视三张投影、材料清单和图上的问题（行不齐、悬空、方块名写错……），自己看着改；满意了在一个坐标盖起来。开工前（服务器开了 RCON 时）整座房子先以白模（不透明的白色方块，像建筑师的体块模型）出现在那里，发光的描边按材料上色（木头橙、石头灰、玻璃浅蓝、门和火把黄……），隔着墙、在远处也看得清，她每放好一块，那一格的虚影就消失。身体照图纸一块块放：先算材料（不够就告诉她缺多少）；从下往上一层层砌，门、火把这类最后放；楼梯、门按图纸的朝向放；够不着的地方垫方块爬上去，盖完把脚手架拆掉；每盖完一层告诉她一声。也有几张常见建筑的参考图纸（小木屋、瞭望塔、围墙、木桥、下界传送门门框），她可以照着改。图纸最大宽 16、深 16、高 12。
- **种地、养动物**：种什么、种在哪、多大、什么时候收、喂哪种动物都是她定。身体去清掉地上的草、用锄头锄地、播种（小麦、胡萝卜、土豆、甜菜，一块地最大 9×9），耕地 4 格内没有水会告诉她长得慢；收庄稼只收熟了的，捡起来再补种回去，没熟的告诉她长到第几阶段；繁殖拿对的饲料一对一对喂（牛羊吃小麦、猪吃胡萝卜、鸡吃种子），报生了几只小的；剪羊毛用剪刀。在地里走时不挖耕地、不从庄稼上跳，踩坏的格子补锄补种。栅栏、羊圈用盖房子画。
- **形状图纸**：大的、圆的、斜的东西（穹顶、圆塔、尖顶、拱）不用一格格画，用形状写，一行一个：`box` / `sphere`（可以只要上半球）/ `cylinder` / `cone` / `pyramid` / `arch` / `line`，带材料、`hollow`（空心，外壳是封闭的）、`open`（空心时哪一头不封口），`cut` 挖门洞窗户，`blueprint 名字 at x y z` 把另一张图纸（字符图也行）放进来；`repeat N step dx dy dz` 画一排（窗户、柱廊），`mirror x / z / xz` 画对称（楼梯、门的朝向跟着翻）；`roof 楼梯 from … to …` 用楼梯铺坡屋顶（`gable` 人字顶、`hip` 四坡顶，朝向自动算，`fill` 补山墙，`overhang` 出檐）。渲染图里台阶画半块、楼梯画成真的台阶形状，屋顶的坡看得出来。工具把形状画进格子（格子中心落在形状里就算），她看三张投影、一张渲染图（用游戏 jar 里方块贴图的颜色画的立体图，东南、西南、西北、东北四个角各一张；`game_act` 把图一起交给她），`view` 看某一层的切片和只画到那一层的切开图，自己改。最大 256×256×256、100 万块；大的图纸预览会缩小显示。造型、比例、材料、怎么组合都是她定的。
- **创造模式**：开局设置里选「创造」（要开 RCON）。开局时把她切成创造模式；盖房子不用材料，先放虚影，再用 RCON 从下往上一层层放，看的人看得到建筑一层层长出来（几秒到一分钟），放完一层撤一层虚影；盖到一半可以停。她站在要盖的地方时先被挪到房顶上。生存模式还是身体一块块放。
- **看地形**（`look`）：一张以她为中心 65×65 格的俯视图（地面方块的颜色，水是蓝的，越亮越高，附近的平地用彩框圈出来），加几行文字：她在哪（在水下会说）、水占多少、地面多高、平地的坐标和大小。找地方盖房子之前先看一眼。
- **草稿和导播**：`site 图纸名 x y z` 在那里放出这张图纸的白模，之后改同名图纸白模跟着变，`build` 不写坐标就盖在那里。草稿出现、开始盖的时候，摄像机离开她，挂到一个看不见的展示实体上，平滑地绕着那块地转；她去做别的事、盖完 5 秒、或者三分钟没动静就回到她身后。`show 建筑名`：她飞到能看全那座建筑的地方、面朝它，摄像机绕它转一圈给看的人看。
- **游戏页上的设计稿**：她看过的图（图纸的渲染图、切开图、地形图）在游戏页那块「画面在游戏客户端窗口里」的地方显示，最新的一张铺满，下面一排是前几张，点了能翻看。
- **挖指定的一格**（`dig`）：挖坑、挖水渠、拆东西；挖开会让岩浆流进来的不挖，要特定镐子才掉东西的会说要什么镐。
- **桶、下界传送门**：她能用桶装水、装岩浆、倒在某一格（倒完告诉她那里变成了什么：岩浆源碰到水变成黑曜石，下界里水一倒就蒸发），能拿着东西对一格方块用一下（打火石点火）。黑曜石用钻石镐挖，或者往岩浆源上倒水浇出来；门框用参考图纸 `nether_portal`（10 块黑曜石），点火以后走进去就到了下界。换维度时告诉她到了哪，两头的门记进世界日志；已经站在门里时，身体先退一步再进去。在下界不放床（会爆炸）。
- **世界日志**：一个服务器上的她一本（存在 DSH 主目录 `dsh-game/minecraft-worlds/`），连着几天玩同一个世界时能接着上次。她写下的目标、存好的图纸、用 `mark` 记的地点（家、矿洞、村庄……哪里值得记由她定），和身体做完的事（盖过的房子、种过的地、睡过的床、死在哪、这局结束时在哪做什么）都记在里面，开局时作为事实交给她；`journal` 看整本。开了 RCON 时记下世界种子，服务器换了新世界会另开一本。开局设置下面能看这本日志、清空它（旧的改名留着）。
- **世界不会停下来等她**：她说话、想事情的时候身体照样在做事。身体自己会：自动吃东西、挨打还手、看到苦力怕靠近就跑开、溺水时先浮上来再游到岸边。时刻由事件推给她：挨打、天黑、怪物靠近、事情做完、有人在游戏里说话、有人进出、死了。
- **看她的画面：摄像机客户端**。插件会开一个真的 Minecraft 客户端（离线账户 `DaFeiYuCam`），自动切成旁观模式挂在她身上，画面就是她的视角：
  - 默认是「跟拍」：镜头在她身后斜上方，跟着她走的方向转，不跟着她低头、扭头甩；身后被挡就换个方向拍（矿道里顺着矿道拍），离她总在 1.8 格以上，不会钻进脑袋里；钻进一格宽的小坑、哪都放不下镜头时退回她的视角。镜头是一个跟着她走的展示实体，要 RCON。
  - 「游戏」标签页里的「跟拍 / 她的视角 / 背后 / 正面」按钮切换（后三个是原版的人称：往摄像机窗口发 F5，不用碰它；原版背后视角在窄地方会被拉到贴着她的后脑勺）。
  - 摄像机窗口不抢焦点、不锁鼠标，点它也不会把你的鼠标关进游戏里；最小化、挪开都行。
  - 原版旁观别人时不显示那个人的血量和物品栏，所以插件自己画了一层 HUD（红心、鸡腿、盔甲、氧气、经验条、快捷栏，物品图标用游戏自己的贴图），贴在摄像机窗口下沿，跟着窗口走。
  - 不想开摄像机的话，在开局设置里关掉，用你自己的客户端进服、切旁观看她。
- **开局设置**：在游戏库里选中 Minecraft，横幅下面就是。改了就保存，保存完马上重新检查一遍。
  - 玩法：「她自己玩」。「和你一起玩」（你用自己的客户端进同一个服务器）是下一阶段。
  - 服务器地址、端口、她在游戏里的名字；摄像机的名字、HUD 网页端口、RCON 端口和密码、`.minecraft` 目录、Java 路径（后两个不填就自动找）。
  - 底下逐项写着检查结果：服务器连没连上（什么版本、几个人在线）、名字对不对、这个版本的客户端装没装、Java 在不在、RCON 密码对不对、HUD 端口有没有被占。有问题时「让大肥鱼玩」按钮不能点，并写出原因；她自己开局时也先查一遍。
- **直播**：OBS 用「窗口捕获」抓摄像机窗口，再加一个「浏览器源」，地址填 `http://127.0.0.1:7391/`（开局设置里的 HUD 网页端口），大小和窗口捕获一样、叠在它上面，血量和快捷栏就在画面上了。浏览器源由 OBS 自己渲染，远程桌面断开也不影响。和直播插件 dsh-livestream 一起用时，在播期间她的话由直播插件念，游戏画面也由它放上舞台。
- **现在的局限**：只在 1.21.4 上测过（名字不对时会告诉她这个版本里相近的名字）；服务器要是离线模式；不会种地和养动物；为了够一个方块，她可能会爬到高处。

## 需要

- Windows，DSH `0.2.0-rc.2` 网页版，DSH 里已经配好 DeepSeek 模型。
- 从 Steam 安装《心跳文学部》（免费）。插件会自己在 Steam 的各个库目录里找；装在别处的话，在设置页填游戏目录。
- 可选：豆包语音合成。不配就只有字幕，没有声音。
  - 一般只要**新版控制台的一个 API Key**：在火山引擎「豆包语音」控制台开通「豆包语音合成模型 2.0」，到「API Key 管理」里创建，填进设置页。大肥鱼的默认音色（萌丫头 2.0）、狼人杀的角色和法官都是 2.0 音色，都用它。
  - 旧版控制台的 APP ID 和 Access Token 只有你把大肥鱼换成 1.0 音色时才需要（火山引擎说旧版控制台以后会下线）。
  - 设置页上方会写着现在的密钥念得出哪些声音。
- 玩 Minecraft：
  - 一个 **Java 版服务器**，`online-mode=false`（她用离线账户进服）。要开摄像机的话还要开 RCON：`server.properties` 里 `enable-rcon=true`，设一个 `rcon.password`。
  - 开摄像机的话，电脑上装好**和服务器同一个版本**的 Minecraft 客户端（HMCL 或官方启动器装的都行，不需要正版账号）和它带的 Java 21。

## 安装

还没有发布到 npm，目前要先从源码构建：

```bash
git clone https://github.com/luckui/dsh-game.git
cd dsh-game
pnpm install
pnpm -C packages/dsh-game build
```

然后在 DSH 侧边栏点「插件」→「添加插件」，填 `packages/dsh-game` 的绝对路径，安装后启用。
插件会自带一个 agent 预设「大肥鱼玩游戏」：只有人设和游戏工具，没有文件读写和 shell。

## 用法

1. DSH 侧边栏点「游戏」，打开游戏库。
2. 选一款游戏，点「▶ 让大肥鱼玩」（《心跳文学部》有存档时是「▶ 让大肥鱼继续玩」）。DSH 会开一个新会话，切到游戏布局，她自己去打开游戏。狼人杀和 Minecraft 先看一眼横幅下面的开局设置：Minecraft 要服务器开着、检查全是 ✓ 才能开局。
3. 游戏画面下面的输入框可以跟她说话。标题栏右边的「■ 停止」让她停下，狼人杀的牌桌也停在下一句话之前；停住后按钮变成「▶ 继续」，点了（或者在输入框跟她说话）她就接着玩。「✕ 结束这局」（点两下）把这局收掉；《心跳文学部》只断开、卸掉 mod，游戏窗口要你自己关。标题栏写着这局现在的状态：进行中 / 暂停中 / 已结束 / 没有游戏。
4. 画面小的话点标题栏的「▭ 影院模式」：收起 DSH 顶上的标题和标签页、右边的思考终端和我们的标题栏，游戏画面变大；按钮浮在画面左上角，「◧ 退出影院」恢复。「⛶ 全屏」让游戏画面单独全屏（按钮和狼人杀的行动条也在里面），录视频时用它。

## 设置

侧边栏「插件」→ dsh-game，页面里就是设置，改完点「保存」，不用重启 DSH。

| 设置 | 默认 | 说明 |
|---|---|---|
| 豆包语音 API Key（新版控制台） | 空 | 一般只填这一个。存进 DSH 凭据，不写进设置文件，页面上只显示配没配 |
| 豆包语音 APP ID / Access Token（旧版控制台） | 空 | 只有大肥鱼用 1.0 音色时才要 |
| 大肥鱼的音色 | 萌丫头 2.0（`zh_female_mengyatou_uranus_bigtts`） | 豆包音色 ID：2.0 音色、复刻音色（`S_` 开头）或 1.0 音色 |
| 打码 | 开 | 给游戏里的死亡、自残、血腥画面打码（直播和录视频建议开着） |
| 导演模式 | 开 | 日常段落快进成摘要，关键段落放慢 |
| 摘要模型 | `deepseek-official/deepseek-flash` | 快进摘要用的模型 |
| 《心跳文学部》游戏目录 | 空（自动在 Steam 库里找） | 有 `DDLC.exe` 的那一层 |

打码、导演模式和游戏目录在下一次打开游戏时生效，其他的马上生效。狼人杀的座位和 Minecraft 的服务器、摄像机不在这里，在游戏库里各自的开局设置里。

## 它对你的电脑做了什么

- 玩的时候往游戏的 `game/` 目录放一个 Ren'Py mod（`zz_dsh_game.rpy`）、一个配置文件和打码图片，插件停止时删掉。mod 只在本机（`127.0.0.1`）和插件通信。
- 游戏画面由 mod 在本机推给 DSH，不上传。
- 存档用游戏自己的存档目录，另外占一个存档位 `dsh-game-resume`。
- 《心跳文学部》的剧情本身会改动游戏文件（比如 `characters/` 里的角色文件）；想回到原样，在 Steam 里「验证游戏文件完整性」即可。
- 联网：游戏库的封面从 Steam CDN 下载并缓存在 DSH 主目录；语音发给豆包；快进摘要和她的思考走你在 DSH 里配的模型。
- Minecraft：
  - 她的「身体」是一个后台的 Node 子进程（mineflayer），用离线账户连你填的服务器。
  - 开摄像机时启动一个 Minecraft 客户端：用你 `.minecraft` 里装好的版本和库，但有自己的游戏目录（DSH 主目录下的 `dsh-game/mc-camera/`，设置和日志不碰你自己玩的那份）；缺资源文件时启动器会从 Mojang 官方补下载。
  - 通过 RCON 给服务器发 `gamemode spectator`、`spectate`、`data get entity` 这几条命令，把摄像机挂在她身上。
  - 切视角时往摄像机窗口发 F5 按键（不激活它）；摄像机窗口被设成「不可激活」。Minecraft 进游戏时会把鼠标锁在自己窗口里，插件会把它留下的锁定解开，DSH 被强行结束后下次加载时也会清掉。
  - 摄像机窗口上的 HUD 是一个透明、点击穿透的小窗口（PowerShell 现场编译的 C#）；HUD 网页开在本机端口 7391，只监听 `127.0.0.1`。
  - 一局结束（或 DSH 关掉）时，身体、摄像机客户端和 HUD 一起关掉。
