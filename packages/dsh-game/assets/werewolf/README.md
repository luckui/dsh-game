# 狼人杀美术：来源与许可

本目录是狼人杀用到的图片：九位角色的立绘（`claude.jpg`、`deepseek.jpg` ……）、主人的头像（`owner.jpg`）、五张身份牌（`card-*.jpg`）、古堡大厅背景（`hall.jpg`）、游戏库的封面和卡片（`cover.jpg`、`capsule.jpg`）。

## 怎么做的

全部由 AI 生成（OpenAI Codex 的图像生成），再缩放压缩成 JPG。

- 九位角色的形象来自互联网上广泛流传的「AI 娘化」meme：各家 AI 被画成二次元少女，在大量 AI 生成和转发中逐渐固定下来，没有单一的原作者。DeepSeek（大肥鱼）的形象同样来自社区 meme，动画片段的说明见 [`../dafeiyu/LICENSE.md`](../dafeiyu/LICENSE.md)。
- 身份牌、大厅、封面和主人的头像是按文字描述生成的。
